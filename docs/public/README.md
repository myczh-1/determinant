# Public Documentation

This directory contains only writing rules, binding rules, and language boundaries for AAL-generating AI.

- [AAL Authoring Guide](./aal-authoring-guide.md)
- [Binding Guide](./binding-guide.md)
- [中文文档](./README.zh-CN.md)

English is the default dialect and uses filenames without a language suffix. Chinese uses `.zh-CN`.

These documents describe the current implemented P0 surface and identify capabilities that are not implemented yet. Runnable examples live under `examples/`; project context, migration status, and repository engineering notes remain in the parent `docs/` directory.
